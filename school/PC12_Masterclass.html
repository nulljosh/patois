ΣUnit 1Sequences & Series

Arithmetic

aₙ = a₁ + (n − 1)d Sₙ = n/2 · (a₁ + aₙ) = n/2 · (2a₁ + (n−1)d)
  • d = common difference = a₂ − a₁ (constant gap)
  • Finding n: sub known values into aₙ formula, solve for n
  • Partial sum (terms i to j): Sⱼ − Sᵢ₋₁

Geometric

aₙ = a₁ · r^(n−1) Sₙ = a₁(1 − rⁿ) / (1 − r) [r ≠ 1] S∞ = a₁ / (1 − r) [only when |r| < 1]
  • r = common ratio = a₂/a₁
  • Finding n: n = 1 + log(aₙ/a₁)/log(r) requires r > 0, r ≠ 1 and aₙ/a₁ > 0. For r < 0, use absolute values to find a candidate and check its sign/parity in the original sequence. Handle r = 0, 1, −1 separately; n must be a positive integer.
Convergent vs Divergent — most tested concept

For a geometric series with a₁ ≠ 0 (the all-zero series always converges):

Converges (S∞ exists) iff |r| < 1

Diverges (no S∞) iff |r| ≥ 1

r = −0.99 → |r| = 0.99 < 1 → CONVERGES. Negative r ≠ divergent.

r = 1.01 → |r| = 1.01 ≥ 1 → DIVERGES.

Sigma Notation

Σᵢ₌₁ⁿ (a₁ + (i−1)d) ← arithmetic sum to n terms Σᵢ₌₁ⁿ a₁·r^(i−1) ← geometric sum to n terms

Bottom of sigma = starting index; top = ending index; expression = general term.

Worked Example — Find S∞
Q: Σᵢ₌₁^∞ 8·(−0.5)^(i−1). Find S∞.
1. a₁ = 8, r = −0.5
2. |r| = 0.5 < 1 → converges
3. S∞ = 8 / (1−(−0.5)) = 8/1.5 = 16/3 ≈ 5.33
Worked Example — Find n
Q: Arithmetic seq, a₁=3, d=4. Which term equals 87?
1. aₙ = 3 + (n−1)·4 = 87
2. (n−1)·4 = 84 → n−1 = 21 → n = 22
Worked Example — Two sums to find d
Q: The 4th + 8th terms = 24 and the 6th + 10th terms = 44. Find the first three terms.
1. (a₁+3d) + (a₁+7d) = 24 → 2a₁ + 10d = 24 → a₁ + 5d = 12
2. (a₁+5d) + (a₁+9d) = 44 → 2a₁ + 14d = 44 → a₁ + 7d = 22
3. Subtract (2) − (1): a₁ cancels, 2d = 10 → d = 5, a₁ = 12 − 25 = −13
4. Terms: −13, −8, −3
Worked Example — Radical difference and quadratic n
Q1: √2 + √8 + √18 + … Sum of 13 terms.
1. Simplify first: √8 = 2√2, √18 = 3√2 → d = √2, a₁ = √2
2. S₁₃ = 13/2 (√2 + 13√2) = 13/2 · 14√2 = 91√2
Q2: How many terms of 2, 8, 14, … give a sum of 660?
3. 660 = n/2 (4 + 6(n−1)) = 3n² − n → 3n² − n − 660 = 0
4. n = (1 ± √(1 + 4·3·660))/6 = (1 ± √7921)/6 = (1 ± 89)/6 → n = 15 or −88/6
5. Reject the negative (n counts terms) → n = 15
Worked Example — Geometric: same r either way
Q: x, x+5, x+15 is geometric. Find x.
1. r is the same for any consecutive pair: (x+5)/x = (x+15)/(x+5)
2. Cross-multiply: (x+5)² = x(x+15)
3. x² + 10x + 25 = x² + 15x → 25 = 5x → x = 5
Worked Example — Two geometric sequences with equal nth term
Q: 162, 54, 18, … (r = 1/3) and 2/81, 2/27, 2/9, … (r = 3). Find n where they match.
1. 162(1/3)ⁿ⁻¹ = (2/81)(3)ⁿ⁻¹
2. (1/3)ⁿ⁻¹ = 3^−(n−1), so multiply both sides by 3ⁿ⁻¹: 162 = (2/81)·3^(2n−2)
3. 162 · 81/2 = 6561 = 3⁸ = 3^(2n−2) → 2n − 2 = 8 → n = 5 (both terms = 2)
Term or sum? Read what is asked

"1 file doubles every minute, how many after 18 minutes": count from minute 0. Minute 0 is 1 file, so after n minutes there are 2ⁿ. After 3 minutes that is 8, not 1+2+4+8. After 18 minutes it is 2¹⁸ = 262 144, a single term (a₁₉ if a₁ is minute 0). Use Sₙ only when the question asks for a running total.

Label sequences correctly: constant difference = arithmetic (d), constant ratio = geometric (r). An infinite series written out must end in "…".

Tip

If asked for "sum of terms from term 5 to term 10": compute S₁₀ − S₄. The −1 offset on the start matters.

⇄Unit 2Transformations

General Form

y = a · f( b(x − h) ) + k Mapping rule: (x, y) → (x/b + h, a·y + k), b ≠ 0
ParameterEffectTrap
aVertical stretch by |a|; a<0 reflects over x-axis|a|<1 = compression, not stretch
bHorizontal stretch by 1/|b|; b<0 reflects over y-axisb=2 means compress by ½, NOT stretch by 2
hShifts RIGHT by h (for positive h)y=f(x−3) shifts RIGHT 3, NOT left
kShifts UP by kNothing tricky here
h direction — most common error

y = f(x − h) → shifts RIGHT. The h inside the bracket is subtracted. Positive h = right.

y = f(x − 3): h = 3, shifts 3 right. y = f(x + 3): h = −3, shifts 3 left.

Reflections

  • Over x-axis: multiply outside → y = −f(x)
  • Over y-axis: negate x inside → y = f(−x)
  • Over y = x: swap x and y (this is the inverse)

Inverse Functions

An inverse is a function only if the original function is one-to-one. Restrict its domain if necessary; otherwise swapping x and y gives an inverse relation.

To find f⁻¹(x): swap x and y, then solve for y
  • Domain of f = Range of f⁻¹
  • Range of f = Domain of f⁻¹
  • Graph of f⁻¹ is reflection of f over the line y = x
Worked Example — Identify Transformations
Q: y = −2f(3(x+1)) − 4. State all transformations.
1. a = −2 → vertical stretch ×2, reflect over x-axis
2. b = 3 → horizontal compression to 1/3
3. h = −1 → shift LEFT 1
4. k = −4 → shift DOWN 4
Mapping: (x,y) → (x/3 − 1, −2y − 4)
Tip — Applying the mapping rule

Take key points from the original function. Apply (x/b+h, ay+k) to each. Mapping order: horizontal changes first (divide x by b, shift by h), then vertical (multiply y by a, shift by k).

ƒUnit 3Polynomials

Factoring Decision Tree

  1. Always factor GCF first
  2. 2 terms: diff of squares or sum/diff of cubes
  3. 3 terms, leading coeff = 1: simple trinomial (find p,q)
  4. 3 terms, leading coeff ≠ 1: AC method
  5. 4 terms: factor by grouping
  6. Degree 4 with x² pattern: substitution (let u = x²)
  7. Degree 3+: rational root theorem + synthetic division

Special Products

a² − b² = (a − b)(a + b) a³ + b³ = (a + b)(a² − ab + b²) a³ − b³ = (a − b)(a² + ab + b²)
Cubes — middle sign trap

Sum of cubes (a³+b³): middle term in trinomial is MINUS (a²−ab+b²)

Diff of cubes (a³−b³): middle term is PLUS (a²+ab+b²)

Memory aid: SOAP — Same, Opposite, Always Positive

AC Method (Messy Trinomials)

ax² + bx + c: find p,q where p·q = a·c AND p+q = b Split middle: ax² + px + qx + c, then group
Worked Example — AC Method
Q: Factor 6x² − 13x + 6
1. ac = 6·6 = 36. Find p,q: p·q=36, p+q=−13 → p=−9, q=−4
2. 6x² − 9x − 4x + 6
3. 3x(2x − 3) − 2(2x − 3)
4. (3x − 2)(2x − 3)

Remainder & Factor Theorems

P(a) = remainder when P(x) ÷ (x − a) [Remainder Theorem] P(a) = 0 ↔ (x − a) is a factor [Factor Theorem] Rational roots: ±(factors of constant) / (factors of leading coeff)
Worked Example — Factor Cubic
Q: Factor P(x) = x³ − 5x² − 12x + 36
1. Try rational roots: ±1,±2,±3,±4,±6,±9,±12,±18,±36
2. P(2) = 8−20−24+36 = 0 ✓ → (x−2) is a factor
3. Synthetic division → x³−5x²−12x+36 = (x−2)(x²−3x−18)
4. x²−3x−18 = (x−6)(x+3)
5. P(x) = (x−2)(x−6)(x+3)

Polynomial Graph Characteristics

  • Degree n → max n x-intercepts, max n−1 turning points
  • Leading coeff +, even degree → both ends go UP (the middle may have several turns)
  • Leading coeff −, even degree → both ends go DOWN
  • Leading coeff +, odd degree → left DOWN, right UP
  • Leading coeff −, odd degree → left UP, right DOWN
  • Odd multiplicity at root → graph CROSSES x-axis
  • Even multiplicity at root → graph BOUNCES off x-axis

logUnit 4Exponents & Logs

Exponent Laws

For arbitrary real exponents, use x > 0. Quotients and negative exponents require nonzero bases; x⁰ = 1 requires x ≠ 0. For negative bases and rational powers, reduce m/n first and check real-root restrictions; power-of-power rules do not hold without conditions.

xᵃ · xᵇ = xᵃ⁺ᵇ (product — add exponents) xᵃ / xᵇ = xᵃ⁻ᵇ (quotient — subtract) (xᵃ)ᵇ = xᵃᵇ (power of power — multiply) x⁰ = 1 (zero exponent) x⁻ⁿ = 1/xⁿ (negative — flip) x^(m/n) = ⁿ√(xᵐ) (rational — root of power)

Logarithms

Real logarithms require b > 0, b ≠ 1 and positive arguments. In the rules below A, B and x are positive. Preserve original domain restrictions after combining logs.

log_b(A) = E ↔ bᴱ = A (definition: log = exponent) log_b(AB) = log_b(A) + log_b(B) (product rule) log_b(A/B) = log_b(A) − log_b(B) (quotient rule) log_b(Aⁿ) = n · log_b(A) (power rule) log_b(x) = log(x) / log(b) (change of base)
Log = "what exponent do I need?"

log₂(8) = 3 because 2³ = 8. The log is the exponent. B = base, E = exponent, A = answer (result).

Solving Exponential Equations

  • Same base: 2^(x+1) = 2^5 → x+1 = 5 → x = 4
  • Different base: take log both sides, use power rule
3^x = 10 → x·log3 = log10 → x = log10/log3 ≈ 2.096

Solving Logarithmic Equations (4.5)

  1. State the domain first: every log argument must be > 0
  2. Combine the logs so each side is one log (product, quotient, power rules)
  3. If log_b(A) = log_b(B), then A = B. Otherwise convert to exponential form: log_b(A) = c → A = b^c
  4. Solve the resulting equation
  5. Reject any solution outside the domain — those are extraneous
Worked Example — Extraneous Solution
Q: log₃(x) + log₃(x−8) = 2
Domain: x > 0 and x − 8 > 0, so x > 8
1. Combine: log₃(x(x−8)) = 2 → x(x−8) = 3² = 9
2. x² − 8x − 9 = 0 → (x−9)(x+1) = 0
3. x = 9 or x = −1. Reject −1 (not > 8). Answer: x = 9
Worked Example — Same Base Both Sides
Q: log₂(x) + log₂(x+3) = log₂(5x−1)
Domain: x > 1/5
1. Combine: x(x+3) = 5x − 1 → x² − 2x + 1 = 0
2. (x−1)² = 0 → x = 1. In the domain, so it works.

Growth & Decay

A = A₀ · b^(t/p) [b = growth factor, p = period for one cycle] A = A₀ · (1/2)^(t/h) [half-life: h = half-life period]

Log Scale Applications

  • Richter: measured amplitude ratio = 10^ΔM. ΔM = 3.8 → about 6310× the amplitude. Energy ratio is approximately 10^(1.5ΔM), about 501,187×. The worksheet calls the amplitude ratio “more powerful”; distinguish this from energy.
  • pH: pH = −log[H⁺]; more acidic = lower pH; [H⁺]₁/[H⁺]₂ = 10^(pH₂−pH₁) in the dilute-solution approximation
  • Decibels: dB = 10·log(I/I₀); increase of 10 dB = 10× the sound intensity, not 10× perceived loudness
Worked Example — Change of Base
Q: Solve 5^x = 500
1. log both sides: x·log5 = log500
2. x = log500/log5
3. x = 2.699/0.699 ≈ 3.86
Worked Example — Log Rules Combined
Q: Write log x + 5 log y − 3 log x as single log
1. Combine x terms: (1−3)logx = −2logx
2. Power rule: log(x⁻²) + log(y⁵)
3. Product rule: log(y⁵/x²), with original restrictions x > 0, y > 0

◯Unit 5Rational Expressions & Conics

Fundamentals

A rational expression is polynomial / polynomial. The denominator cannot equal zero.

Non-permissible values: set denominator = 0 and solve → those are EXCLUDED

Operations

OperationMethod
SimplifyFactor top and bottom fully, cancel common factors, state restrictions
MultiplyFactor everything, cancel across numerators/denominators, multiply remaining
DivideRequire the divisor to be defined and nonzero; multiply by its reciprocal, then simplify
Add/SubtractFind LCD (LCM of denominators), convert each fraction, combine numerators, simplify
Restrictions after cancelling

State ALL non-permissible values from the ORIGINAL denominators — even if a factor was cancelled. Restrictions come from before simplification. For division, also exclude zeros of the divisor’s numerator.

Graphing y = a/(x−h) + k

Assume a ≠ 0. If a = 0, this is y = k with a hole at x = h, not a vertical asymptote.

Vertical asymptote: x = h (denominator = 0) Horizontal asymptote: y = k (what y approaches as x → ±∞) a: steepness; a > 0 → Q1/Q3 relative to asymptotes; a < 0 → Q2/Q4
Cheat code — finding 'a' from a graph

Pick any obvious grid point on the graph. Sub its (x,y) into y = a/(x−h)+k and solve for a. Always works.

Solving Rational Equations

  1. Identify all non-permissible values first
  2. Multiply every term by the LCD to clear fractions
  3. Solve the resulting polynomial equation
  4. Check solutions against non-permissible values — reject any that match
Worked Example — Find Equation from Graph
Q: Graph has VA at x=3, HA at y=2, passes through (4,7)
1. h=3, k=2. Form: y = a/(x−3) + 2
2. Sub (4,7): 7 = a/(4−3) + 2 = a + 2
3. a = 5 → y = 5/(x−3) + 2

Conic Sections (5.5)

A conic is what you get when a plane slices a double cone. The angle of the cut decides the shape.

ConicHow the plane cutsStandard form (centre/vertex at (h, k))
CirclePerpendicular to the cone's axis(x−h)² + (y−k)² = r²
EllipseTilted, cuts through one cone only(x−h)²/a² + (y−k)²/b² = 1
ParabolaParallel to the cone's sidey = a(x−h)² + k  or  x = a(y−k)² + h
HyperbolaCuts both cones(x−h)²/a² − (y−k)²/b² = 1  or  (y−k)²/a² − (x−h)²/b² = 1

Spot the Conic from the Equation

Squared termsSignsConic
x² and y², same coefficientsame signCircle
x² and y², different coefficientssame signEllipse
x² and y²opposite signsHyperbola
Only one of x² or y²—Parabola
Ellipse: bigger denominator sits under the long direction. Vertices at ±a along the major axis, co-vertices at ±b. Foci: c² = a² − b² Hyperbola: the positive term tells you which way it opens. Asymptotes: y − k = ±(b/a)(x − h). Foci: c² = a² + b²
Complete the square to find the centre

Group x terms and y terms, factor out any leading coefficient, add the same number to both sides, then rewrite as squares. The centre is (h, k).

Degenerate conics

If the right side comes out as 0, the "conic" collapses: a single point (circle/ellipse form) or two crossing lines (hyperbola form). If it comes out negative, there is no graph.

Worked Example — Circle by Completing the Square
Q: x² + y² − 6x + 4y − 12 = 0. Find centre and radius.
1. Group: (x² − 6x) + (y² + 4y) = 12
2. Add 9 and 4 to both sides: (x−3)² + (y+2)² = 25
3. Centre (3, −2), radius 5
Worked Example — Ellipse and Hyperbola
Q1: 4x² + 9y² = 36. Divide by 36: x²/9 + y²/4 = 1
a = 3, b = 2. Vertices (±3, 0), co-vertices (0, ±2), c² = 5
Q2: x²/16 − y²/9 = 1. Opens left and right, vertices (±4, 0)
Asymptotes y = ±(3/4)x, c² = 25 so foci (±5, 0)

Reference angles and CAST

The reference angle is the acute angle between the terminal arm and the x-axis. Find the ratio at the reference angle using the table, then use CAST to pick the sign.

Graphing — 5 Key Points Method

For one full period of y = a·sin(b(x−h))+k, assume b > 0 and a ≠ 0. If b < 0, first use sin(−u) = −sin(u) to make b positive:

  • Start at phase shift h: y = k (midline)
  • Quarter period: y = k+a (maximum if a > 0, minimum if a < 0)
  • Half period: y = k (midline)
  • Three-quarter period: y = k−a (minimum if a > 0, maximum if a < 0)
  • Full period: y = k (midline, cycle repeats)

For cosine at x = h: y = k+a, a maximum if a > 0 and a minimum if a < 0. If a = 0 or b = 0, the function is constant and has no fundamental period.

Worked Example — Equation from Graph
Q: Graph has max=7, min=1, period=4π, crosses its midline upward at x=π
1. a = (7−1)/2 = 3
2. k = (7+1)/2 = 4
3. b = 2π/4π = 1/2
4. h = π (phase shift right)
5. y = 3·sin(½(x−π)) + 4
Radians vs Degrees

Standard PC12 uses radians. Period formula: T = 2π/|b|. If period is given as "360°" then in radians that is 2π. Always match units.

Phase shift direction

y = sin(x − π/3): phase shift = +π/3 (shifts RIGHT). Same h-direction trap as U2 transformations.

θUnit 7Trig Identities

Foundational Identities

Use identities only where every expression is defined: denominators must be nonzero. In particular cot θ = 1/tan θ holds on their common domain; cot θ itself is defined by cos θ/sin θ wherever sin θ ≠ 0.

Reciprocal: csc θ = 1/sin θ sec θ = 1/cos θ cot θ = 1/tan θ Quotient: tan θ = sin θ/cos θ cot θ = cos θ/sin θ Pythagorean: sin²θ + cos²θ = 1 Derived: tan²θ + 1 = sec²θ 1 + cot²θ = csc²θ
Deriving Pythagorean identities

Start from sin²θ+cos²θ=1. Divide both sides by cos²θ → tan²θ+1=sec²θ. Divide by sin²θ → 1+cot²θ=csc²θ. Don't memorize three — derive from one.

Proving Identities — Strategy

  1. Transform one side into the other, or independently simplify both sides to the same expression
  2. Pick the more complex side to transform
  3. Common techniques (in order to try):
  • Rewrite everything in terms of sin and cos
  • Factor out common terms
  • Get a common denominator to combine fractions
  • Multiply top and bottom by conjugate (1+sinθ, 1−cosθ, etc.)
  • Use a Pythagorean identity to substitute (sin²=1−cos² etc.)
Avoid circular proofs

Starting by assuming the desired equality is not enough. Reversible equivalences can prove an identity when justified on the original domain, including nonzero denominators; transforming one side is usually the clearest method.

Sum & Difference Formulas

sin(A ± B) = sinA·cosB ± cosA·sinB cos(A ± B) = cosA·cosB ∓ sinA·sinB (note: ∓ flips the sign) tan(A ± B) = (tanA ± tanB) / (1 ∓ tanA·tanB)

Double Angle Formulas

sin(2A) = 2·sinA·cosA cos(2A) = cos²A − sin²A = 1 − 2sin²A = 2cos²A − 1 tan(2A) = 2·tanA / (1 − tan²A)
Three forms of cos(2A)

All three are equivalent via sin²+cos²=1. Pick whichever form makes the target expression cleanest. If the target has only cos, use 2cos²A−1.

Solving Trig Equations

  1. Isolate the trig function (treat sinθ or cosθ like a variable)
  2. Find the reference angle using inverse trig
  3. Identify which quadrants give the correct sign
  4. List all solutions in the given domain
  5. General solution: add 2πn to each sine/cosine argument solution, or πn for tangent, n ∈ ℤ; then solve for the original variable. For sin(bθ+c), the θ-period is 2π/|b|, not necessarily 2π.
Worked Example — Solving with Identity
Q: Solve 2sin²θ − sinθ − 1 = 0, θ ∈ [0, 2π]
1. Factor: (2sinθ + 1)(sinθ − 1) = 0
2. sinθ = −½ → θ = 7π/6, 11π/6
3. sinθ = 1 → θ = π/2
Solutions: θ = π/2, 7π/6, 11π/6

√Unit 8Functions & Radicals

Master Move

y = a·f( b(x − h) ) + k
  • a: vertical stretch, negative flips over the x-axis
  • b: horizontal stretch by 1/b, negative flips over the y-axis
  • h: slide right by h (inside is backwards)
  • k: slide up by k
  • Stretches and flips first, slides second. Factor b out of the bracket before reading it

Compositions

f(g(x)): g runs first, its output goes into f
Worked Example
f(x) = x − 4, g(x) = x² + 4
f(g(x)) = (x² + 4) − 4 = x²
g(f(x)) = (x − 4)² + 4
f(g(2)) = f(8) = 4, g(f(3)) = g(−1) = 5

Radical Functions

  • Parent √x starts at (0, 0), domain x ≥ 0, range y ≥ 0
  • Start point: set the inside to 0, then read y
  • √(−x) heads left, −√x heads down. Inside flips left/right, outside flips up/down
  • √f(x): point (x, y) becomes (x, √y). y = 0 or 1 stay put, y < 0 vanishes, 0 < y < 1 rises
Traps

√ gives one positive root, never ±

A minus outside the root flips vertically only

Inverse of x² needs x ≥ 0 first, giving √x

πUnit 9Trig Graphs & Equations

Sinusoidal Graphs

y = a·sin(b(x − h)) + k
  • Amplitude |a|, period 2π/|b|, phase shift h, midline y = k
  • From a graph: amplitude = (max − min)/2, midline = (max + min)/2, b = 2π ÷ period
  • A bigger b speeds up the wave, so it compresses horizontally

Tangent

  • tan x = sin x / cos x, the steepness of the terminal arm
  • Asymptotes where cos x = 0, period π, passes through (0, 0), no amplitude
